AProxy

Приложение HTTP/HTTPS/Socks5 proxy под Андройд.
Compose + Kotlin.
Позволяет поднимать прокси сервер и раздавать интернет используя точку доступа.
Можно отдельно включать и выключать HTTP, HTTPS или Socks5.
В основном экране приложения отображается временной график upload и download.
Просит перейти в системные настройки для отключения экономии батареи приложением.

## Что умеет

- **HTTP-прокси** — абсолютные URL и `CONNECT`-туннели для HTTPS-сайтов.
- **HTTPS-прокси** — тот же HTTP-прокси, но сам слушает TLS. Сертификат можно
  отправить на клиентское устройство прямо из приложения.
- **SOCKS5** — метод без авторизации, команда `CONNECT`, IPv4/IPv6/домены.
- Каждый протокол включается отдельно и имеет собственный порт
  (по умолчанию `8080`, `8443`, `1080`).
- Живой график скорости и объёма трафика за последние 60 секунд, суммарный
  трафик и количество подключённых клиентов.
- Адрес устройства и готовые адреса прокси с копированием по нажатию.
- Переход в настройки точки доступа.
- Foreground-сервис с уведомлением, кнопкой «Остановить» и wake lock —
  прокси продолжает работать при свёрнутом приложении.
- Запрос исключения из оптимизации батареи.
- Русская и английская локализация.

## Как пользоваться

1. Включите точку доступа Wi-Fi на телефоне (кнопка «Настройки точки доступа»
   в приложении откроет системный экран).
2. Включите нужные протоколы и при необходимости измените порты.
3. Нажмите «Запустить прокси» и разрешите уведомления.
4. На клиентском устройстве, подключённом к точке доступа, укажите прокси:
   - HTTP: `IP_ТЕЛЕФОНА:8080`
   - HTTPS: `IP_ТЕЛЕФОНА:8443`
   - SOCKS5: `IP_ТЕЛЕФОНА:1080`

IP-адрес отображается в карточке «Подключение»; нажмите на строку, чтобы
скопировать адрес. На типичной точке доступа это `192.168.43.1`,
`192.168.49.1`, `192.168.232.1` или `192.168.1.1`.

### HTTPS-прокси и сертификат

Это не MITM-прокси: HTTPS-режим означает, что клиент подключается к самому
прокси по TLS, а внутри работает обычный HTTP-прокси. Приложению нужен
самоподписанный сертификат, которому должен доверять клиент.

- Включите HTTPS, нажмите «Сертификат» и отправьте `aproxy.crt` на клиент.
- Установите сертификат как доверенный (CA certificate).
- Сертификат лежит в `app/src/main/assets/aproxy.p12`
  (alias `aproxy`, пароль `aproxy`, CN `aproxy.local`). В SAN добавлены
  `localhost`, `aproxy.local`, `127.0.0.1` и типовые адреса точек доступа.
- Если клиент строго проверяет имя хоста, используйте адрес из SAN либо
  отключите проверку имени для прокси.

### Экономия батареи

На многих прошивках система убивает фоновые процессы. Карточка «Экономия
батареи» открывает системный запрос на исключение приложения из ограничений.
Если прямого запроса нет, откроются настройки батареи — найдите AProxy и
разрешите работу в фоне.

## Сборка

Требования: JDK 17+ (проверено на JDK 21), Android SDK с платформой 35 и
Build-Tools 35.

```bash
export JAVA_HOME=/path/to/jdk-21
export ANDROID_HOME=/path/to/Android/Sdk
# либо создайте local.properties со строкой sdk.dir=/path/to/Android/Sdk

./gradlew :app:assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

Проверка кода и тесты:

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug
```

Тесты поднимают настоящие HTTP, HTTPS (TLS) и SOCKS5 прокси и прогоняют через
них трафик до локального echo-сервера.

Проект также открывается в Android Studio (Gradle 8.11.1, AGP 8.7.3,
Kotlin 2.0.21, Compose BOM 2024.12.01).

## Структура

```
app/src/main/java/com/aproxy/app/
├── MainActivity.kt              # Activity + Compose
├── AProxyApplication.kt         # канал уведомлений
├── proxy/
│   ├── ProxyEngine.kt           # жизненный цикл всех слушателей
│   ├── HttpProxyServer.kt       # HTTP и HTTPS (TLS) прокси
│   ├── Socks5Server.kt          # SOCKS5
│   ├── SocketProxyServer.kt     # accept-loop, учёт клиентов
│   ├── TrafficMeter.kt          # счётчики и история скоростей
│   ├── ProxyConfig.kt           # модель настроек
│   ├── TlsContext.kt            # загрузка PKCS#12 из assets
│   └── ProxyUtils.kt            # парсинг, чтение заголовков, relay
├── service/ProxyService.kt      # foreground-сервис и уведомление
├── ui/                          # экран, график, диалог порта, тема
└── util/                        # SharedPreferences, IP, батарея, сертификат
```

Порты и переключатели сохраняются в `SharedPreferences`, поэтому после
перезапуска процесса сервис поднимается с прежней конфигурацией.

## Ограничения и безопасность

- В прокси нет авторизации: любой, кто видит порт в локальной сети, может им
  пользоваться. Не запускайте прокси в недоверенных сетях и не пробрасывайте
  порты наружу.
- SOCKS5 поддерживает только `CONNECT`; `BIND` и `UDP ASSOCIATE` не реализованы.
- Приложение не включает точку доступа программно (ограничение Android), а
  открывает системный экран настроек.
- Wake lock и работа сервера расходуют батарею; для длительной работы
  рекомендуется исключение из оптимизации.
- `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` и тип foreground-сервиса `specialUse`
  требуют отдельного обоснования при публикации в Google Play.
- Для HTTPS-прокси используется самоподписанный сертификат из репозитория.
  Для постоянного использования выпустите свой сертификат и замените
  `app/src/main/assets/aproxy.p12`.
